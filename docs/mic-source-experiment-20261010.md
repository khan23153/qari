This APK changes only native capture source preference from VOICE_RECOGNITION-first to MIC-first; VOICE_RECOGNITION and UNPROCESSED remain fallbacks. Existing requested rate44100Hz with16kHz fallback,3x gain, FIR resampling,100ms uploads, model weights, confidence .55, RMS .006, live window7.5s and tier2 policy are unchanged. The Hifz rendering/markers/summary flow are unchanged. Android's official guidance says VOICE_RECOGNITION preprocessing is disabled by default; it does not guarantee AGC/noise suppression as the old source comment assumed. MIC processing is device-dependent, so this is an experiment requiring a new real phone recording, not a proven recognition improvement.

New app versions report version/build in the authenticated start handshake and allowlisted native capture rate, selected source, gain, conversion and dropped-buffer-frame count through the existing WebSocket. A per-start generation ID travels through the native start intent/status; cached previous-capture headers cannot identify a new or failed capture. The ID is stripped from the existing on-screen diagnostic text and is not sent to the server. Reading-status telemetry is suppressed until current-generation capture-start and deduplicated so it does not add recurring upload work when unchanged. No raw native status, token, device identifier or arbitrary client text enters these diagnostics. The backend validates type/range/enum, logs only permitted technical fields and persists the metadata in the existing owned session hash; incoming owner/status/session-id fields cannot alter ownership or reference data. The optional metadata store write has a100ms deadline; a Redis stall cannot indefinitely block incoming PCM/ping/stop. Older clients remain supported. Diagnostics do not supply recognition evidence or words.

[Android preprocessing specification](https://source.android.com/docs/core/audio/implement-pre-processing), checked2026-10-10. This does not establish the exact path used by the user's standalone recorder or proprietary Tarteel app.
